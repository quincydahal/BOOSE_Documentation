Class ExtendedStoredProgram
Extended implementation of the BOOSE StoredProgram class. This class adds application-specific support for:
  • Methods and method calls
  • IF / ELSE / END IF control flow
  • FOR / END FOR loops
  • WHILE / END WHILE loops
It manages additional stacks and lookup tables required for correct control-flow linking and execution.
Syntax
C#
    public class ExtendedStoredProgram : StoredProgram
