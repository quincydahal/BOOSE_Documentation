Documentation Preview
Method RunProgram
Parses and runs the BOOSE program currently contained in the program editor textbox (textBox1). Reuses the existing StoredProgram, Parser and CommandFactory instances created in the constructor. Before each run the stored program is reset so that any previous commands and variables are cleared. Any errors are written to the output window (textBox2).

C#
