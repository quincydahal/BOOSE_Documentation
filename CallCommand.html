Class CallCommand
Implements the BOOSE call command. This command invokes a previously defined method, passing arguments to its local parameters and transferring control to the method body.
Syntax
C#
    public class CallCommand : Command, ICommand
Remarks
The command relies on MethodTable to locate method declarations and on ReturnStack to manage return addresses.
