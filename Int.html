Class IntCommand
Implements the BOOSE int command. This command supports declaration and assignment of integer variables. Integer values may be defined using literal values, variables, or arithmetic expressions evaluated at runtime.
Syntax
C#
    public class IntCommand : Evaluation, ICommand
Remarks
Supported examples:
  • int radius = 50
  • int width
  • width = 2 * radius
