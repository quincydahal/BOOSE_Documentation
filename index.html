Core Application Classes

  • AppCanvas Handles drawing operations, canvas bitmap, shapes, and pen movement.
  • Form1 Main Windows Form containing UI controls and output panel.

Command Classes

  • CircleCommand Implements drawing of circles with optional fill behavior.
  • ClearCommand Clears Canvas.
  • CommandFactory Factory responsible for creating command objects.
  • DrawToCommand Moves the pen to new coordinates while drawing a line.
  • MoveToCommand Moves the pen to a specified position without drawing.
  • PenCommand Changes pen color.
  • RectCommand Draws rectangles at the current pen location with width and height.
  • ResetCommand Resets the pen and its position to 0,0.
  • TriCommand Draws Triangle at the current pen location with width and height.
  • WriteTextCommand Renders text at the pen position.

  • PenUnitTest Checks pen color mode changes for correctness.
