BOOSE Canvas App – Documentation

This page links to the auto-generated documentation for the commands and unit tests of the BOOSE Canvas App project.

Command Classes

  • CircleCommand Draws circles with optional fill.
  • ClearCommand Clears the canvas without moving the pen.
  • CommandFactory Creates command instances for the app.
  • DrawToCommand Draws a line from the current position.
  • MoveToCommand Moves the pen without drawing.
  • PenCommand Changes the drawing colour.
  • RectCommand Draws rectangles, filled or outline.
  • ResetCommand Resets canvas, pen and position.
  • TriCommand Draws outline triangles.
  • WriteTextCommand Renders text at the pen position.

Unit Test Classes

  • CircleUnitTest Tests for the circle command.
  • DrawToUnitTest Tests for line drawing behaviour.
  • MoveToUnitTest Tests for pen movement without drawing.
  • PenUnitTest Tests for pen colour changes.
  • RectUnitTest Tests for rectangle drawing.
  • TriUnitTest Tests for triangle drawing.
  • WriteTextUnitTest Tests for text rendering.
