Class WriteTextCommand
Implements the BOOSE write command. This command outputs text to the canvas at the current cursor position. It supports:
  • Literal strings (e.g. write "Hello")
  • Variables (int, real, boolean)
  • Arithmetic expressions (including real-number math)
  • String concatenation using the + operator
