Class EndMethodCommand
Implements the BOOSE end method command. This command marks the end of a method definition and is responsible for returning control to the instruction following the corresponding call command.
Syntax
C#
    public class EndMethodCommand : Command, ICommand
Remarks
The command relies on ReturnStack to retrieve the return address saved by a call command. If no return address is available, execution is considered invalid.
