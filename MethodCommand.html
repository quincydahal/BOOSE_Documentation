Class MethodCommand
Implements the BOOSE method command. This command defines a reusable method block with an optional return type, method name, and local parameters. Method bodies are skipped during normal program execution and executed only when invoked via a call command.
Syntax
C#
    public class MethodCommand : Command, ICommand
Remarks
Supported syntax:
  • method int myMethod a, b
  • method real compute
Method linkage (start/end positions) is handled by LinkControlFlow.
