Class AppCommandFactory
Application-specific command factory for the BOOSE language. This factory is responsible for mapping BOOSE command keywords (e.g. moveto, circle, if, for, call) to their corresponding ICommand implementations.
Syntax
C#
    public class AppCommandFactory : CommandFactory
Remarks
Drawing-related commands are constructed with a shared ICanvas instance, while control-flow and variable commands are created without a canvas dependency. Any command name not recognised here is delegated to the base CommandFactory implementation.
