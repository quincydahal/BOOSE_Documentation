Class SetCommand
Implements the BOOSE set command. This command performs variable assignment using the syntax:
C#
set variableName = expression
Syntax
C#
    public class SetCommand : Evaluation, ICommand
Remarks

In the user interface (Form1), assignment expressions such as x = expr are automatically converted into set x = expr before parsing.

This command supports both integer and real variables and evaluates expressions at runtime, allowing variables and arithmetic expressions.
