Class BooleanCommand
Implements a boolean variable command for the BOOSE language. This command supports declaration and assignment of boolean variables. Boolean expressions may consist of:
  • Boolean literals (true, false)
  • Logical operators (&&, ||, !)
  • Boolean variables
  • Numeric expressions (non-zero = true)
Syntax
C#
    public class BooleanCommand : Evaluation, ICommand
Remarks
BOOSE internally stores variable values as integers. This command therefore bridges boolean values to integers using 1 for true and 0 for false.
