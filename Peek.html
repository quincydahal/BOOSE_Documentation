Class PeekCommand
Implements the BOOSE peek command. This command reads a value from a specified index of an array and assigns it to an existing target variable.
Syntax
C#
    public class PeekCommand : Command, ICommand
Remarks
Supported syntax:
  • peek targetVar = arrayName index
The command supports both integer and real arrays. Type checking is enforced to ensure that the target variable matches the array type.
