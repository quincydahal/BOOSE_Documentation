Class ForCommand
Implements the BOOSE for loop command. This command controls iteration using a loop variable, a start value, an end expression, and a step value. It integrates with the extended control-flow mechanism to support nested loops and correct loop termination.
Syntax
C#
    public class ForCommand : Command, ICommand
Remarks
Supported syntax:
  • for i = start to end step n
The loop variable is created or updated during initialization, and the loop condition is evaluated at runtime to determine whether execution should continue or exit the loop.
