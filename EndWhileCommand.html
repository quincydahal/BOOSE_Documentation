Class EndWhileCommand
Implements the BOOSE end while command. This command marks the end of a while loop and is responsible for linking back to the corresponding WhileCommand. During execution, it determines whether the loop should repeat or terminate.
Syntax
C#
    public class EndWhileCommand : Command, ICommand
Remarks
The command works in conjunction with ExtendedStoredProgram by using the BlockStack and LoopStack to ensure that while / end while blocks are correctly matched, including support for nested loops.
