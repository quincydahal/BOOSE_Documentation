Class PokeCommand
Implements the BOOSE poke command. This command assigns a value to a specific index of an array. It supports integer and real arrays, and allows the index and value to be specified as literals, variables, or expressions.
Syntax
C#
    public class PokeCommand : Command, ICommand
Remarks
Supported syntax:
  • poke arrayName index = value
